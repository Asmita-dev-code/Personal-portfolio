# Personal Portfolio Website

A clean and modern personal portfolio website designed and developed using **HTML5 and CSS3**. This project showcases my personal profile, web design interests, and a simple introduction through a responsive and visually appealing landing page.

## ✨ Features

* Clean and modern portfolio design
* Navigation bar with menu items
* Personal profile section
* Introduction and professional tagline
* Profile image
* "Hire Me" call-to-action button
* WhatsApp contact button
* "Contact Me" button
* Custom color variables using CSS
* Google Fonts integration
* Flexbox and CSS Grid layout
* Modern button styling with gradients and rounded corners

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Google Fonts**

  * Poppins

1. Clone this repository:

